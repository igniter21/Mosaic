Understand this tab

Click the Mosaic toolbar icon on any page, YouTube video, offline article, or PDF document. Mosaic extracts up to 6,000 characters of clean context, sends that single excerpt to your configured AI model, and stores a verifiable local memory.

For local files & offline articles (file:///): In Brave or Chromium, open brave://extensions (or chrome://extensions), click Details on Mosaic Memory Collector, and turn ON "Allow access to file URLs".

Do not enable a source until it is also enabled in Mosaic. The API address must be an allowed local host declared in the extension manifest.
